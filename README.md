# 📊 Velora Fashion – Annual Sales Dashboard 2025

## 📌 Project Overview

The **Velora Fashion Annual Sales Dashboard** is an interactive Excel dashboard designed to analyze and visualize e-commerce sales performance.

The dashboard provides a consolidated view of sales, orders, order status, sales channels, customer demographics, and state-wise performance. Interactive slicers allow users to filter the dashboard based on **Month, Category, and Channel**.

## 🎯 Objectives

- Analyze monthly sales and order trends
- Understand order fulfillment and cancellation patterns
- Identify the best-performing sales channels
- Analyze sales performance across different states
- Compare sales between men and women
- Understand customer order patterns across age groups and gender
- Provide an interactive and easy-to-understand sales report

## 📊 Dashboard Insights

The dashboard includes the following visualizations:

### 1. Orders vs Sales
Shows the monthly relationship between total sales amount and number of orders.

### 2. Order Status
Breaks down orders into:
- Delivered
- Refunded
- Returned
- Cancelled

### 3. Orders by Channel
Shows the contribution of different e-commerce channels to total orders, including:
- Amazon
- Flipkart
- Myntra
- Meesho
- Ajio
- Nalli
- Others

### 4. Top 5 States by Sales
Highlights the five states generating the highest sales.

### 5. Sales: Men vs Women
Compares the overall sales contribution from male and female customers.

### 6. Age Group vs Gender
Analyzes order distribution across different customer age groups and gender.

## 🎛️ Interactive Filters

The dashboard includes interactive Excel slicers for:

- **Month**
- **Category**
- **Channel**

Users can select different combinations of filters to dynamically analyze the data.
